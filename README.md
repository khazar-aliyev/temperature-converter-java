# Temperature Converter in Java

A simple Java console application that converts temperatures between **Celsius** and **Fahrenheit** using conditional ternary operators and formatted output.

## Features
- Dynamic temperature unit conversion (C to F or F to C).
- Case-insensitive unit input (`toUpperCase()`).
- Compact logic using ternary operator (`? :`).
- Precision formatting (`%.2f`) for clean decimal representation.

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Run `Khazar.java`.
4. Enter the current temperature and desired unit (`C` or `F`).
